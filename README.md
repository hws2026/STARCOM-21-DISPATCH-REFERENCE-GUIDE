# STARCOM 21 Dispatch Website

STARCOM 21 is a fully styled FiveM roleplay dispatch reference website featuring live radio scripts, call-specific procedures, 10-codes, call signs, and quick-reference tools for Prairie State Roleplay.

## GitHub Pages

1. Upload **all files** in this folder to the repository root.
2. Open **Settings → Pages** in the GitHub repository.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.
5. GitHub Pages will use `index.html` as the home page.

Do not upload only `index.html`; the site also requires `styles.css`, `app.js`, and the individual call-page HTML files.
